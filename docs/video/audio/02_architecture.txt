Here's the whole flow. A failed payment comes in. A rule classifier maps it to a cause using Razorpay's own documented fields. If that's ambiguous, an LLM takes a pass, but it can abstain instead of guessing. Either way, a planner proposes an action, and a deterministic policy gate, not the AI, decides whether that action is actually allowed. The LLM only ever writes a label or a sentence. It never touches a money API.
