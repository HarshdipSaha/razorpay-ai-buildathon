## Direction contract

THESIS: The report reads as an audit dossier, not a dashboard — evidence pinned to exhibits, not metrics decorating cards. Refuses the hero-metric-card template every AI-generated report defaults to.

OWN-WORLD: Near-black ground (#0a0b0d), bone-white ink (#e8e6df), one warm signal-amber accent (#e8a33d) reserved for the case number and active exhibit tags. Traffic-signal semantics for state — a muted sage green for `allow`, amber for `escalate`, a desaturated red for `block` — never used decoratively. Registration crosshairs mark each exhibit's corner. Hairline rules (1px, #2a2c30) divide every section; no cards, no shadows, no rounded corners above 2px. Type: one mono face (ui-monospace stack, self-contained, no fetch) for labels/data/hashes at tracked uppercase, one humanist sans for prose. Every section is numbered as an EXHIBIT, not a card.

STORY: A judge opens the report and reads it as a case file: a case header (subscription batch, seed, run date), then EXHIBIT A (the invariants — must read as a clean verdict stamp), EXHIBIT B (per-cause disposition, traffic-signal coded), EXHIBIT C (classifier findings with confusion matrix), EXHIBIT D (citations — every classification's source field, literally "chain of evidence"), EXHIBIT E (the audit chain, styled as a custody ledger with visible hash linkage), EXHIBIT F (exceptions, styled as flagged/unresolved items), closing with the AI-usage disclosure as a signed statement.

FIRST VIEWPORT: A case-file header spanning the top: case number (derived from data), "REBOUND — BATCH AUDIT REPORT", run metadata (scenario count, seed, duplicates rejected) in mono caps, and immediately below it the VERDICT strip — three invariants (double charges / policy violations / false escalations) rendered as a stamped verdict block, large tabular numerals, green when zero, red when not — this is the thesis in one glance: the report opens on the verdict, not a hero metric.

FORM: Candidate 4 of 7 (forensic evidence/exhibit board), raised with Kraftwerk's traffic-signal state vocabulary (declined challenger, donated: allow/block/escalate color semantics) and the design-annual plate section's registration-mark + hairline-rule precision (competitive challenger, donated: corner crosshairs, mono caps, grid discipline). FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
